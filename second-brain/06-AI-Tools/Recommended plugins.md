# Recommended plugins (optional, later)

**Philosophy:** core plugins first. Add community plugins only when friction is real. Cap at ~3–5.

## Core (already configured in this vault)
Daily Notes · Templates · Backlinks · Outgoing links · Graph · Canvas · Properties · Bookmarks · Note composer · Command palette · Workspaces · Random note · Slash command · Bases (if present)

## Community (install yourself when ready)

| Plugin | Why |
|--------|-----|
| **Templater** | Dynamic templates (dates, prompts) beyond core Templates |
| **Calendar** | Click-to-open daily notes |
| **Dataview** | Query notes as tables (projects by status) |
| **QuickAdd** | Capture macros → Inbox |
| **Periodic Notes** | Weekly / monthly review automation |
| **Obsidian Git** | Commit/push from inside Obsidian (optional; CLI is fine) |

## How to install
1. Settings → Community plugins → Turn on community plugins  
2. Browse → install → Enable  
3. Prefer defaults; avoid huge plugin stacks  

## Not required for a working second brain
Themes cosplay, dozens of CSS snippets, AI chat plugins on day one. Capture + links + PARA + weekly review beats decoration.
