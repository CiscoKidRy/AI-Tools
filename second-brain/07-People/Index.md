# People

Personal CRM: **one note per person** for facts, context, and links to projects/areas.

This is separate from PARA on purpose. People are not projects—they connect *across* projects over time.

**Template:** [[Templates/Person]]

## How to use
1. Create `07-People/First Last.md` (or preferred name) from the Person template.  
2. Log durable facts (role, preferences, family, history)—not every chat.  
3. **Link** related `[[Projects]]`, meetings, and decisions.  
4. After a meeting: update the person note + the project note (both directions).  
5. Sensitive stuff: keep private; **never** put secrets, passwords, or confidential employer data you shouldn’t store in git.
