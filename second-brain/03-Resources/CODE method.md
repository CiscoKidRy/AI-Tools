# CODE method

## Summary
A pipeline for turning information into output:

1. **Capture** — save what resonates, fast  
2. **Organize** — file by actionability (PARA)  
3. **Distill** — progressive summarization so future-you finds the gold  
4. **Express** — create with your notes (ship work, write, decide)

## Key points
- Capture and Organize are different speeds; don’t mix them.  
- Distill on revisit, not on first dump.  
- A second brain fails if you only Capture and never Express.
