# Atomic notes and linking

## Summary
One note ≈ one idea, written in your words, connected with `[[wikilinks]]`. Folders group; **links think**.

## Key points
- Prefer many small linked notes over one mega-document.  
- Add **at least one** outgoing link when creating an atomic note.  
- Backlinks surface unexpected connections over time.  
- Graph view is a diagnostic, not a daily dashboard.  
- Don’t over-link: link when a relationship is real and useful.

## Practice
Use [[Templates/Atomic idea]] and place notes under `03-Resources/` (or a project if only temporary).
