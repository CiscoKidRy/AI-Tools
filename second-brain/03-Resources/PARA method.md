# PARA method

## Summary
Organize information by **actionability**, not by topic.

| Letter | Meaning |
|--------|---------|
| **P**rojects | Goals with a deadline / finish line |
| **A**reas | Ongoing standards of care |
| **R**esources | Topics and reference material |
| **A**rchives | Inactive items kept for search |

## Key points
- Prefer moving notes as actionability changes.  
- Folders are coarse buckets; links carry meaning.  
- When unsure: capture to Inbox, decide later.
