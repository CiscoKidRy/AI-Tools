## How to process (CODE → Organize)

For each item, ask: *Is this a Project, Area, Resource, or Archive?*

1. Create/move note into the right PARA folder (use a template).  
2. Add at least one `[[wikilink]]` if it’s knowledge.  
3. Delete pure noise.  
4. Keep this list short—process weekly if not daily.
