# Counsel of Agents — rules recommendations (2026)

Summary of multi-agent debate on durable CLI AI rules. Full narrative lived in a Grok session; this file is the durable takeaway.

## Consensus now (2026)
- Short constitution (~one page)
- Project how-to (build/test/run)
- Always / Ask / Never boundaries
- Verify after non-trivial changes
- Autonomy on local/reversible; confirm on shared/destructive
- Earn rules from repeated failures

## Still essential ~2036
- Intent / authority
- Secrets & blast radius
- Verification over assertion
- Honesty about what was not checked
- Memory / learning governance
- Human-defined non-goals

## Likely to fade
- Style micro-rules, personality novels, mandatory planning for one-liners, huge generated architecture dumps

## Layering
| Layer | Holds |
|-------|--------|
| Global rules | Authority, security, verification duty, communication |
| Project AGENTS.md | Commands, architecture, domain taboos |
| Skills | Repeatable procedures |
| CI / hooks | Binary enforcement (format, secret scan, tests) |
